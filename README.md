- **Counter/** - Counter project examples

## Getting Started

To use any of these sketches:

1. Download and install the [Arduino IDE](https://www.arduino.cc/en/software)
2. Connect your Arduino board via USB
3. Open the desired `.ino` file in the Arduino IDE
4. Select your board type and COM port
5. Upload the sketch to your Arduino

## Requirements

- Arduino board (Uno, Nano, Mega, etc.)
- Arduino IDE or compatible IDE
- USB cable for uploading sketches
